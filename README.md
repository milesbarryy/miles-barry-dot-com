# miles-barry-dot-com

Personal site for Miles Barry — a single static `index.html`, no build step and no dependencies.

Plain-text layout: flowing prose paragraphs with inline links, a soft gray-blue
gradient background, and contact links at the bottom. No lists, no navigation.

Hosted with GitHub Pages from the `main` branch root.

## Editing

Open `index.html` and edit the paragraphs directly. Each block is a plain `<p>`;
links are ordinary `<a>` tags inside the sentences.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
