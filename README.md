# miles-barry-dot-com

Personal site for Miles Barry — a single static `index.html`, no build step and no dependencies.

Hosted with GitHub Pages from the `main` branch root.

## Editing

Open `index.html` and edit the content directly. Each block on the page is one
`<section>`; list bullets are colored dots set with an inline `background` on
`<span class="dot">`.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
