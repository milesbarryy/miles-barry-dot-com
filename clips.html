Three clips, with a note on my role in each. Where I built a graphic that did not run with the published story, both are linked and labeled.

01

Another bad year for seal pups

The Point Reyes Light · Summer 2026

Published version · Interactive map (not published)

I reported and wrote this piece, interviewing Sarah Codde, a National Park Service marine ecologist, and Richard Vacha, a local tracker. It was edited by the paper’s editor in chief before publication. Separately, I built the interactive map in R from the park service’s harbor seal monitoring data, 1997–2025, and its 2026 monitoring update, to understand the population dynamics underlying the story. The map did not run with the piece; it is published here alongside it.

02

Creek swimming holes get poor marks for cleanliness

The Point Reyes Light · Summer 2026

Published version · Interactive chart (not published)

I reported and wrote this piece. I also built the accompanying chart from State Water Resources Control Board monitoring data (CEDEN and BeachWatch) and Marin County monitoring records, plotting bacteria concentrations at each swimming hole across the April–October 2025 sampling season on a logarithmic scale, with each site able to be added or removed for comparison. As with the seal map, the chart did not run with the published story.
